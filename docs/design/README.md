# Design documents

Numbered `NNNN-slug.md`. Each carries a status line and relations (`Depends on`,
`Supersedes`, `Specializes`, `Parent`, `Co-normative with`). Umbrella documents
group children as `NNNN.1-slug.md`. Archive a dead child by renaming it to a
leading dot. When an invariant and a design document conflict, fix one in the
same commit.
